다루는 영역

"장사"와 "행정"이라는 두 가지 다른 일 중, 행정을 대행합니다

사업자등록·법인 설립부터 산업재해 신고, 특허·지재권 출원 안내까지 — 관할 부서를 확인하고 필요한 서류·순서를 한 번에 하나씩 안내합니다. 정부24·data.go.kr(서류 발급) → gdoc.go.kr(전자문서 제출) → dpaper.kr(진본 확인·보관)로 이어지는 공공데이터·전자정부 인프라 위에서 작동합니다.

인프라역할현재 상태
data.go.kr(공공데이터 API)사업자등록 관련 증명·소득 자료 등 서류 발급 요청부분 구현 — API 개방 기관은 자동 처리
정부24 / gdoc.go.kr서류 발급·제출 창구, 상시 제출·수신부분 구현
dpaper.kr(정부 전자문서지갑)제출 서류 진본 확인·위변조 방지부분 구현 — 정식 이용 신청 접수, 승인 진행 중
세 가지 영역
1
사업자 등록·법인 설립
사업자등록(홈택스·관할 세무서) → 위생교육 이수 → 영업신고 → 소방시설 완비증명 → 원산지표시판 등록, 직원 채용 시 4대보험 성립신고까지. 순서가 꼬이면 접수 자체가 안 됩니다.
2
산업재해 신고
사고 정황을 먼저 정리해 묻고, 어떤 기관에 어떤 순서로 신고해야 하는지 안내합니다. 법적 판단·과실 여부 확정은 즉시 노무사·변호사 연결로 이어집니다.
3
특허·지재권 출원 안내
키프리스(KIPRIS) 등에서 유사 선행 사례를 조회·정리하고, 출원 절차 각 단계에서 준비할 것을 안내합니다. 신규성·진보성 판단, 청구항 작성은 변리사 영역입니다.
정직한 한계

전문가의 최종 판단은 대신하지 않습니다

시군구별 담당 부서 실시간 조회, 반경 내 상권·경쟁 밀집도 분석, 리뷰 답글 초안 작성은 오늘 기준 실제로 동작(LIVE)합니다. 사업자등록·영업신고 서류 자체의 자동 작성, 4대보험·세금 신고 기한의 자동 추적은 아직 로드맵 단계입니다.

⚠
사고 경위의 법적 판단·과실 확정 — 노무사·변호사에게 반드시 연결됩니다.
⚠
특허 청구항 작성 — 변리사의 전문 영역으로 남습니다. K-Biz는 절차 안내와 서류 준비를 대행할 뿐입니다.
⚠
서류 자동 작성·기한 자동 추적 — 사업자등록·영업신고 서류 자체의 자동 작성, 4대보험·세금 신고 기한의 자동 추적은 아직 로드맵 단계입니다.
